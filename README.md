# דומינו בהנדסה גנטית

אפליקציית משחק כיתתי חי עם 32 קוביות דומינו מאוירות.

## זרימה
- `/` — פתיחת משחק חדש למורה.
- `/teacher?code=...&token=...` — מסך מורה.
- `/join?code=...` — מסך תלמיד.
- `/projector?code=...&token=...` — תצוגת מקרן.

## פריסה
הפרויקט מותאם ל-Vercel ומבוסס על `@vercel/functions` Cache ו-QR serverless function.
