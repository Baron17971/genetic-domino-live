# DomiKnow

משחק דומינו כיתתי חי שבו המורה יוצר/ת מאגר זוגות של מושגים, שאלות ותשובות, והתלמידים בונים יחד שרשרת ידע.

## מסכים
- `/` — יצירת משחק חדש.
- `/teacher?code=...&token=...` — מסך מורה.
- `/join?code=...` — כניסת תלמידים.
- `/projector?code=...&token=...` — תצוגת מקרן.

## פריסה
הפרויקט מותאם ל־Vercel ומבוסס על `@vercel/functions` ו־QR serverless function.
